# ragdock KB 索引

> 状态：现行，4 个专题。新增前先查本索引，同一主题只保留一篇现行正文。

KB 保存可复用的部署、接入、交付和排查经验。业务边界与架构取舍以根目录 `README.md` 为准，全局约束看 [CLAUDE.md](../../CLAUDE.md)，文档导航看 [docs/README.md](../README.md)。

## 如何使用

1. 先按任务判断影响面，只读命中主题，不通读全部 KB。
2. 长文用 `rg -n '关键词|^##' docs/kb/<文件>.md` 定位，再按章节读取。
3. 写入 KB 须用户明确要求创建、更新或整理；普通修复不自动授权回写。
4. 编号一旦分配不再复用；主题被取代时归档，不重排编号。
