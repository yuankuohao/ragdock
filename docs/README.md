# ragdoc 文档导航

> 开源、可私有化部署 RAG 交付套件：RAGFlow + LiteLLM + 企业微信适配层。

## 快速导航

### 知识库
→ **[知识库索引 (kb/README.md)](kb/README.md)**

部署、模型切换、企微接入、离线交付的现行操作与排查入口。先按触发场景选一篇，不通读。

### 全局约束
→ **[CLAUDE.md](../CLAUDE.md)** / **[AGENTS.md](../AGENTS.md)**

改动范围、配置入口、密钥、版本、验证与交付的硬约束。任何任务开始前先读，再按需加载单篇 KB。

## 文档结构

```
docs/
├── README.md        # 本文件：文档导航
├── kb/              # 知识库：操作与排查（不是产品文档）
│   ├── README.md    # 索引，含「何时翻它」
│   ├── KB写作规范.md
│   └── NNN_主题.md
└── archive/         # 被取代的历史材料（按需建立）
```

## 分工

- 根目录 `README.md`：项目是什么、为什么这样拆、怎么快速跑起来。
- `docs/kb/`：出问题怎么查、迁移怎么操作、交付怎么打包。
- `CLAUDE.md`：所有任务都必须遵守的约束；专项细节写进对应 KB。
- 同一事实只在一处维护，其他地方引用。
